Explicit behavior: cancellation keeps existing assigned tasks for manual reassignment; completed tasks awaiting inspection count as outstanding load; future tasks are counted through the selected service date. Multiple confirmed shifts use the smallest explicitly entered non-null workload limit. A break is not available work. Worker start requires actual current confirmed working time; managers retain their operational oversight action. No payroll, statutory rest, shift recurrence policy or guessed task duration is calculated.

Task attachments are additive metadata preparation, not a completed photo workflow. Actual photo upload/private access, repair comments/attachments atomicity and return-to-service, guest request parity and authoritative check-in readiness are still required in the next independently reviewable P2-B block. C–G are not declared implemented by this PR.

No production changes, production migrations, deployment, paid infrastructure creation or merge were performed. External Keycloak/staging, provider contract and approved backup/restore gates remain NOT VERIFIED.
